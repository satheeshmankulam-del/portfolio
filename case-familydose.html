Designers Can Ship Now.

The story behind FamilyDose — a medication tracker built by a UX designer, powered by stubbornness. How a sick child, a sleepless night, and an AI coding partner became a real app on the Play Store.

Designer + Product Owner

01 — The Story

It started with
a fever.

My kid was sick, and my wife and I were taking turns through the night. Medicines every six hours, but which one did we give last? Was it the tablet or the syrup? Did we already give the second dose? We were exhausted, second-guessing ourselves, scribbling on paper that kept going missing.

That night I thought: this is a UX problem.

"I design interfaces and interaction flows. I know Figma inside out, I can sketch a user flow in my sleep. But ask me to write a line of code? I'd have stared at you blankly — until I built FamilyDose."

So I decided to build it myself. A simple medicine log. Free. No subscriptions, no accounts, no nonsense. Just something a tired parent or a caretaker could open and say — yes, this dose was given, at this time.

The brief was clear: build a medication tracker that works offline, requires no account, and is designed for family-level management — not just individual use.

02 — The Build

Claude as coding partner,
wife as tester.

🤖
Claude as coding partner
I used Claude and Android Studio as my build environment. I fed it my Figma sketches and described user flows in plain English — the way I'd write a design brief. Claude generated the code.
👩‍💻
Wife as sharpest tester
My wife sat beside me almost every evening — tapping through screens, flagging what felt confusing, questioning flows I'd convinced myself were obvious. No filter, no politeness. Exactly what I needed.
🌙
Sleepless nights on token limits
One of the earliest walls I hit was token limits — they ran out faster than I expected. I spent sleepless nights experimenting. Prompting effectively took me nearly a week to figure out even after going Pro.
🐛
Real bugs from real users
After launch, a close friend picked it up and used it for real. He came back with small but important bugs. We fixed them together. Nothing about this was solo — the product shaped itself around real use.
03 — The Hard Parts

Play Store rejections,
cryptic errors, and wanting to quit.

01
Designing 40+ screens before writing code
Mapped the core flows in Figma first: add medication → set schedule → view today's doses → mark as taken → history. Designed all edge cases, empty states, and error states before touching Android Studio.
02
Figma designs → plain English → Claude → working code
Each screen and interaction described in plain language — the way I'd write a design spec. Claude generated the React JSX. I iterated on the generated code until every screen matched the Figma designs.
03
Real device testing — the screens that looked broken
Tested specifically on Samsung, OnePlus, and Xiaomi — notorious for killing background processes. Fixed alarm persistence by implementing foreground service notifications and battery exemption prompts.
04
Play Store submission — passed review on first attempt
There were nights I wanted to quit. Play Store rejections, cryptic build errors. But the moment the app passed review and went live — I sat there staring at a Play Store listing with my name on it.

used by real families.

Whether AI will replace engineers or replace designers is still a loud argument. But what I know from living it is this: that gap — the one that used to keep ideas locked inside Figma forever — is closing fast.

FamilyDose is free, offline, and available on Google Play. Trilingual — English, Malayalam, and Hindi. With PIN lock, JSON export, image lightbox, and 100-entry cap with compression.

If you're a designer sitting on an idea, waiting until you "learn to code properly" — stop waiting. You already understand the user. You already know what good feels like. Go build the thing.
